# The Leprechaun Inn

A multi-page business website for a fictional Irish pub based in Athlone, Co. Westmeath.

Built as a project for QQI Level 5 Software Development at Moate Business College.

## Pages

- **Home** — pub intro, history, and opening hours
- **About Us** — background and story of the establishment
- **Merchandise** — products and pricing table
- **Music & Events** — live music schedule and event listings
- **Gallery** — photo gallery with slideshow
- **Contact Us** — contact details and enquiry form

## Technologies Used

- HTML5
- CSS3 (animations, transitions, slideshow)
- JavaScript (image slideshow with dot navigation)

## Features

- Multi-page navigation with active page highlighting
- Animated image slideshow with fade transitions
- Responsive gallery layout
- Fixed background image with parallax feel
- Contact form
